## 💡 Жоба туралы

Көптеген адамдар мен кәсіпкерлер ай сайын немесе жыл соңында банк үзінділерін (выписка / statement) жүктейді. Алайда жүздеген, мыңдаған транзакциялардан тұратын PDF құжаттарын қолмен оқу, шығындар мен кірістердің қайда кеткенін есептеу өте көп уақыт алады, ал банктік деректерді сыртқы серверлерге немесе белгісіз боттарға жүктеу қауіпті.

**Bank Statement Analyzer** осы мәселені түбегейлі шешеді:
- Барлық операциялар **тікелей сіздің құрылғыңызда (браузерде)** орындалады.
- Құжаттар ешқайда жіберілмейді (Zero Network Data Transfer).
- Қазақстанның негізгі банктерінің форматтарына бейімделген ақылды парсерлер қолданылады.

## 🌟 Негізгі мүмкіндіктер мен артықшылықтар

### 1. Автоматты банк пен үлгіні анықтау (Zero-Click Auto-Detection)
- PDF құжатын жай ғана браузерге сүйреп апарсаңыз (Drag-and-Drop), жүйе оның қай банкке тиесілі екенін мәтіндік қолтаңбалары арқылы өзі таниды.
- Интерфейс автоматты түрде сол банктің ресми түсіне, логотипіне және стильдік градиентіне бейімделеді.

### 2. Заманауи интерактивті аналитикалық тақта
- **Басты қаржылық көрсеткіштер**: Бастапқы баланс, соңғы қолжетімді баланс, нақты кіріс, нақты шығыс, таза өзгеріс (Net) және ішкі аударымдар.
- **Интерактивті динамикалық график (HTML5 Canvas)**: Күндік кірістер (жасыл), шығыстар (қызыл) және таза қалдық өсімі (көк) сызықтары. Retina/HiDPI қолдауы, нөлдік сызық бөлінісі, 1 күндік нүктелік режим.
- **Күнтізбелік жылу картасы (Heatmap Calendar)**: Шығындардың қай күндері көп болғанын көрсететін GitHub стиліндегі визуалды тор.
- **«Адамдар» бөлімі (P2P Transfers)**: Аударым жасалған контрагенттерді (қазақ және латын қарпіндегі есімдер: Дінмұхамед Ж., Лəззат П., т.б.) автоматты топтастырып, олармен болған айналымды көрсету.
- **Апта күндерінің орташа шығыны**: Әр апта күні бойынша күнтізбелік орташа шығынды нақты есептеу.
- **Ерекше / Ірі шығындар индикаторы**: Орташа шектен асып кеткен күндерді автоматты анықтау.

### 3. Ақылды санаттау және бюджетті жоспарлау
- **Қазақстандық нарыққа бейімделген категориялау**: Азық-түлік, Тамақ/Асханалар (Тағам, Донер, Шашлык, кафелер), Электроника (Мечта, Sulpak, Technodom), Дәріхана (Биосфера, т.б.), Көлік, Байланыс (Tele2, Kcell, Beeline), Білім (ЖОО, колледждер), Сервистер (Claude.ai, OpenAI, Google) және т.б.
- **50/30/20 қаржылық ережесі**: Кірістердің Мұқтаждықтарға (50%), Қалауларға (30%) және Жинаққа (20%) бөлінуін бақылау.
- **Категорияларды қолмен түзету**: Кесте ішінде кез келген транзакция санатын өзгерту және жазба (note) қалдыру (LocalStorage-де есте сақталады).

### 4. Жылдам сүзгі және Debounce іздеу
- Жүздеген немесе мыңдаған транзакциялар болса да, 250 мс debounce арқасында іздеу теру кезінде интерфейс мүлде қатпайды.
- Санаттар, операция түрлері (кіріс, шығыс, аударым, қолма-қол), күндер және айлар бойынша лезде сүзгілеу.

## 💻 Жергілікті іске қосу (Quick Start)

Жобаны өзіңіздің компьютеріңізде іске қосу үшін күрделі құралдарды (Node.js/npm) орнатудың да қажеті жоқ. Кез келген қарапайым веб-сервер жеткілікті:

### 1-қадам: Репозиторийді жүктеп алыңыз
```bash
git clone https://github.com/Azamaperdeev05/bank-analizer.git
cd bank-analizer
```

### 2-қадам: Жергілікті серверді қосыңыз

**Python 3 арқылы (ең оңай жолы):**
```bash
python3 -m http.server 8080
```

**Немесе Node.js арқылы:**
```bash
npx serve .
```

**Немесе PHP арқылы:**
```bash
php -S localhost:8080
```

### 3-қадам: Браузерді ашыңыз
Браузерде [`http://localhost:8080`](http://localhost:8080) мекенжайына өтіп, банк үзінді көшірмеңізді жүктеңіз!

## 🚀 Өндіріске орналастыру

Бұл жоба толықтай статикалық болғандықтан, кез келген заманауи платформада 1 минутта жарияланады:

### Vercel арқылы:
1. GitHub репозиторийіңізді [Vercel](https://vercel.com/) платформасына қосыңыз.
2. Баптауларын қалдырыңыз (Framework: `Other`, Build Command: бос, Output Directory: `.`).
3. Репозиторийдегі [`vercel.json`](./vercel.json) қауіпсіздік тақырыптарын (Content-Security, MIME-types) автоматты түрде реттейді.

### GitHub Pages арқылы:
1. Репозиторийдің **Settings ➔ Pages** бөліміне өтіңіз.
2. **Branch: main**, **Folder: / (root)** таңдап, «Save» батырмасын басыңыз.
